서버 연동 방식
🖥️

이 확장은 백엔드 서버를 통해 작동합니다.
별도의 API 키 설정이 필요하지 않습니다.

음성 인식(Whisper), 명령 해석(Claude), YouTube 검색에 필요한 API 키는 모두 서버에서 안전하게 관리됩니다.

백엔드 서버 연결됨 — voice-browser-backend-youngho.vercel.app
음성 응답 설정
음성으로 결과 읽기 명령 실행 결과를 한국어 음성으로 읽어줍니다
🎙️ OpenAI 자연어 음성(nova)을 사용합니다. 인터넷 연결이 필요합니다.
대화 컨텍스트
컨텍스트 기억 사용 이전 명령을 기억해서 "거기서", "방금 그거" 같은 표현을 이해합니다
ℹ️ 최근 5개 명령까지 기억합니다. 다른 사람이 사용할 때는 기록을 지우세요.
키보드 단축키
음성 명령 시작 팝업을 열지 않아도 어느 페이지에서나 바로 녹음을 시작합니다
Ctrl+Shift+1
⌨️ 단축키 변경은 chrome://extensions/shortcuts 에서 가능합니다.
ℹ️ 문제가 발생하면 인터넷 연결 상태를 확인하거나, 잠시 후 다시 시도해주세요.
