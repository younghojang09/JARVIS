⚙️ Voice Browser 설정

API 키는 브라우저 로컬 스토리지에만 저장되며 외부로 전송되지 않습니다.

API 키 설정
음성을 텍스트로 변환하는데 사용됩니다.
텍스트 명령을 브라우저 액션으로 변환하는데 사용됩니다.
노래나 영상 자동 재생을 위해 필요합니다. "아이유 틀어줘" 같은 명령에 사용됩니다. 발급: Google Cloud Console에서 YouTube Data API v3 활성화 → 사용자 인증 정보 → API 키 생성

⚠️ API 키는 chrome.storage.local에 저장됩니다. 공용 컴퓨터에서 사용 시 저장 후 반드시 로그아웃 및 키를 삭제해주세요.
